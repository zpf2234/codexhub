# Security model

CodexHub is a metadata index, not a scanner or an endorsement service. The indexer reads public GitHub metadata and selected text files only. It never clones, installs dependencies, executes workflows, runs MCP servers, or follows arbitrary scripts from indexed repositories.

Report a vulnerability in CodexHub through GitHub Security Advisories. For a dangerous or misleading catalog entry, open an issue with the repository URL and evidence. Do not include credentials or private data.
