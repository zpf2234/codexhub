# Scoring rubric

The score is a quality signal out of 100, not an endorsement or security audit.

| Dimension | Points |
| --- | ---: |
| Specification conformance | 40 |
| Documentation | 20 |
| Maintenance | 20 |
| Distribution hygiene | 10 |
| Transparency | 10 |

Stars, forks, watchers, and commit counts are displayed separately and never add quality points. Missing required metadata caps the specification score. Unknown licenses keep an entry visible but unranked. Metadata older than seven days is visible but excluded from active rankings. Every awarded check has an evidence path in the generated catalog.
