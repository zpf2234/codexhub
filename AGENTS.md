# CodexHub contributor guide

## Project expectations

- Keep catalog data evidence-backed and reproducible.
- Never clone, install, execute, or connect to an indexed project.
- Run `npm test` and `npm run build:offline` before opening a pull request.
- Treat stars and forks as popularity signals, never as quality evidence.
- Render catalog text as text, not HTML, and allow only `http`/`https` links.
