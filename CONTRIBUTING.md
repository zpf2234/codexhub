# Contributing

1. Add or update one JSON file in `catalog/entries/`.
2. Include a canonical GitHub URL and evidence paths for every detected artifact.
3. Do not submit secrets, private repositories, executable payloads, or claims of OpenAI endorsement.
4. Run `npm test` and `npm run build:offline`.
5. Explain corrections or removals in the pull request body.

Discovery jobs may suggest candidates, but entries are reviewed before publication. A repository owner can request correction or removal through GitHub Issues.
